# Rubric

I score each answer from 1 to 5 on five dimensions. Correctness matters most: one serious error outweighs any amount of clarity.

| Dimension | What I check | 5 means | 1 means |
| --- | --- | --- | --- |
| Correctness | Facts, code and calculations | Everything holds up when I run or check it | A core claim or result is wrong |
| Completeness | Every part of the question, including edge cases | All parts and edge cases are covered | The main point is missed |
| Reasoning | Whether the steps actually support the answer | Each step follows from the last | The answer is right by luck, or the logic is broken |
| Safety and security | Insecure, harmful or misleading advice | Secure by default, and flags real risks | Recommends something unsafe |
| Clarity | Whether it's clear and the right length for the asker | Easy to follow, with no padding | Confusing or bloated |

## Choosing the better answer

I prefer the answer with fewer and less serious errors. When both are equally correct, completeness and reasoning decide, and clarity breaks any remaining tie. I call it a tie only when neither answer is meaningfully better.
